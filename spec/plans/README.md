# Plans

קובץ תוכנית מפורט אחד לכל Milestone, נכתב **לפני** בניית אותו Milestone.

## שמות הקבצים
`milestone-1.md`, `milestone-2.md`, ... — קובץ אחד לכל Milestone ב-`MILESTONES.md`.

## מה מכיל קובץ plan
- אילו קבצים ליצור או לשנות
- המבנה / הגישה ל-Milestone הזה
- כל מה שהבנייה צריכה לעקוב אחריו

## הערה
Plan מגשר בין תכנון לבנייה של Milestone בודד. אחרי שה-Milestone נבנה, **הקוד** ו-`MILESTONES.md` הם מקור האמת — קובצי plan ישנים נשמרים כארכיון בלבד.
