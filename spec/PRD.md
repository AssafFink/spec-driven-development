# PRD – Spec-Driven Development Prompter

## 1. רקע ומטרות

### א. מטרת המוצר
אתר אינטרנט בעל דף יחיד המאפשר למשתמשים לצפות בשבעה פרומפטים לפיתוח מונחה מפרט ולהעתיק אותם בקלות בעברית או באנגלית.

### ב. תיאור הבעיה
משתמשים המעוניינים להשתמש בפרומפטים חוזרים בתהליך Spec-Driven Development זקוקים לגישה מהירה לטקסט המלא של כל פרומפט בשפה הרצויה, ללא פתיחה ידנית של קובצי Markdown. העתקה אוטומטית ל-Clipboard עלולה להיכשל בשל מגבלות הדפדפן, ולכן נחוצה גם חלופת העתקה ידנית.

### ג. תיאור הפתרון
דף Desktop יחיד עם בחירת שפה, שבעה לחצני פרומפטים ואזור תצוגה של הפרומפט הנבחר. לחיצה על לחצן מציגה את תוכן קובץ ה-Markdown המתאים כ-Rendered Markdown ומנסה להעתיק ל-Clipboard את תוכן הקובץ המקורי. האתר מאפשר גם העתקה ידנית של ה-Markdown המקורי מאזור התצוגה.

## 2. קהלי יעד וצרכי משתמשים

### א. User Personas – פרסונות משתמשים
- **משתמש בפרומפטים לפיתוח מונחה מפרט:** אדם המעוניין לבחור פרומפט לפי שלב בתהליך העבודה, לקרוא אותו ולהעתיק אותו לשימוש בכלי אחר. המשתמש עשוי להעדיף ממשק ופרומפטים בעברית או באנגלית.

### ב. User Stories – סיפורי משתמש
- כמשתמש בפרומפטים, אני רוצה לבחור אחד משבעה פרומפטים לפי שם הקובץ, כדי שאוכל להציג את תוכנו ולהעתיק אותו במהירות.
- כמשתמש, אני רוצה לבחור בין עברית לאנגלית, כדי שאוכל להשתמש בממשק ובפרומפטים בשפה הרצויה לי.
- כמשתמש, אני רוצה לראות פרומפט כ-Rendered Markdown, כדי שאוכל לקרוא אותו בצורה נוחה.
- כמשתמש, אני רוצה לקבל אישור על הצלחת ההעתקה או הסבר במקרה של כישלון, כדי שאדע אם עליי להעתיק ידנית.
- כמשתמש, אני רוצה להעתיק ידנית את Markdown המקורי, כולל סימוני העיצוב, כדי שאוכל להשתמש בו גם אם העתקה אוטומטית אינה זמינה.
- כמשתמש חוזר, אני רוצה שהאתר יזכור את השפה האחרונה שבחרתי, כדי שלא אצטרך לבחור אותה מחדש.

## 3. זרימות וחוויית משתמש

### א. User Journey – מסע המשתמש
המשתמש נכנס לאתר ממחשב Desktop כדי למצוא פרומפט לתהליך Spec-Driven Development. הוא רואה את כותרת האתר, את אפשרויות השפה ואת שבעת לחצני הפרומפטים, ובאזור התצוגה מופיעה הנחיה לבחירת פרומפט. לאחר בחירה, הפרומפט מוצג באופן מעוצב ומתבצע ניסיון להעתקת ה-Markdown המקורי. המשתמש מקבל משוב על תוצאת ההעתקה ומשתמש בטקסט שהועתק, או מסמן ומעתיק אותו ידנית אם ההעתקה נכשלה.

### ב. User Flows – זרימות המשתמש

**בחירת פרומפט והעתקה:**
1. המשתמש פותח את הדף בשפה שנשמרה מהביקור הקודם, או בעברית בביקור הראשון.
2. באזור תצוגת הפרומפט מופיעה הודעת הנחיה בשפת הממשק.
3. המשתמש לוחץ על אחד משבעת הלחצנים.
4. האתר טוען את קובץ ה-Markdown התואם לשפה וללחצן, מדגיש את הלחצן הנבחר ומציג את הפרומפט כ-Rendered Markdown.
5. האתר מנסה להעתיק ל-Clipboard את טקסט ה-Markdown המקורי, כולל סימוני העיצוב.
6. האתר מציג הודעת הצלחה או כישלון בשפת הממשק. במקרה של כישלון, ההודעה מנחה להעתקה ידנית מתוך אזור התצוגה.
7. אם המשתמש בוחר פרומפט אחר, התצוגה מתחלפת ומיקום הגלילה חוזר לתחילת הפרומפט החדש.

**החלפת שפה:**
1. המשתמש לוחץ על כפתור 🇮🇱 „עברית” או 🇺🇸 „English”.
2. כותרת הדף, הודעות הממשק, כיווניותו ויישורו מתעדכנים לשפה הנבחרת; שמות שבעת לחצני הפרומפטים נשארים ללא שינוי.
3. הפרומפט הנבחר מתנקה, הדגשת הלחצן מתבטלת ובאזור התצוגה מופיעה הודעת ההנחיה בשפה החדשה.
4. בחירת פרומפט מעתה טוענת ומעתיקה את הקובץ בשפה החדשה.
5. השפה שנבחרה נשמרת לביקורים הבאים.

**כישלון בטעינת פרומפט:**
1. המשתמש לוחץ על פרומפט שקובץ ה-Markdown שלו חסר או אינו ניתן לטעינה.
2. באזור התצוגה מופיעה הודעת שגיאה בשפת הממשק.
3. שאר לחצני הפרומפטים נשארים פעילים.

### ג. UX Requirements – דרישות חוויית משתמש
- דף יחיד המיועד למסכי Desktop בלבד, המחולק לשני אזורים זה לצד זה: לחצני בחירה ואזור תצוגת פרומפט בעל גבול חזותי ברור.
- בעברית: RTL ויישור לימין; לחצני הפרומפטים בטור בצד ימין, ואזור התצוגה משמאלם.
- באנגלית: LTR ויישור לשמאל; לחצני הפרומפטים בטור בצד שמאל, ואזור התצוגה מימינם.
- אזור התצוגה מציג Markdown מעוצב (כותרות, הדגשות, רשימות, טבלאות וכדומה), אך מאפשר העתקה ידנית של טקסט ה-Markdown המקורי עם הסימונים.
- אזור התצוגה גדל בהתאם לאורך התוכן. כשהתוכן ארוך, גוללים את **הדף כולו**, ללא גלילה פנימית באזור התצוגה.
- לחצני הפרומפטים נגללים עם הדף ואינם Sticky.
- בחירה בפרומפט חדש מחזירה את מיקום הגלילה לתחילת הפרומפט החדש.
- לחצן הפרומפט הנבחר בולט בעיצובו; לכל היותר לחצן אחד מודגש בכל זמן נתון.
- הודעות הנחיה, הצלחה ושגיאה מופיעות בשפת הממשק הפעילה.

## 4. דרישות פונקציונליות

### א. Features & Functional Requirements – פיצ'רים ודרישות פונקציונליות

**FR-01 – שפות וממשק:**
- תמיכה בשתי שפות: עברית ואנגלית.
- בחירת שפה באמצעות שני לחצנים המוצגים תמיד עם דגל וכיתוב קבוע: 🇮🇱 „עברית”, 🇺🇸 „English”.
- עברית: כותרת **„פרומפטר לפיתוח מונחה מפרט”**, כיווניות RTL ויישור לימין.
- אנגלית: כותרת **“Spec-Driven Development Prompter”**, כיווניות LTR ויישור לשמאל.
- ברירת מחדל לביקור הראשון: עברית.
- שמירת השפה האחרונה שנבחרה גם לאחר רענון או ביקור חוזר.
- עם החלפת שפה: ניקוי הפרומפט המוצג, ביטול ההדגשה והצגת הנחיית הבחירה בשפה החדשה, ללא העתקה אוטומטית.

**FR-02 – בחירת פרומפט:**
- הצגת שבעה לחצנים אנכיים, בסדר הבא, עם כיתוב זהה בשתי השפות:
  1. `PRD.md`
  2. `ARCHITECTURE.md`
  3. `wireframes.png`
  4. `style-guide.png`
  5. `mockups.png`
  6. `DESIGN.md`
  7. `MILESTONES.md`
- כל לחצן ממופה לפרומפט תואם בשפה הנבחרת. שם הלחצן הוא תווית בלבד ואינו מחייב שקובץ הפרומפט עצמו יהיה מסוג PNG.
- בחירת פרומפט מעדכנת את אזור התצוגה ואת ההדגשה של הלחצן הנבחר, ומתחילה את תצוגת הפרומפט מראשיתה.

**FR-03 – מקור הפרומפטים:**
- שימוש ב-14 קובצי Markdown קיימים: שבעה בעברית ושבעה באנגלית; כל פרומפט נשמר בקובץ נפרד.
- לכל אחד משבעת הלחצנים קיים פרומפט תואם בכל אחת משתי השפות.
- תוכן הפרומפטים נלקח מהקבצים הקיימים ולא נכתב מחדש במסגרת האתר.

**FR-04 – תצוגת פרומפט:**
- באזור התצוגה יוצג הפרומפט הנבחר כ-Rendered Markdown.
- לפני בחירה, וכן לאחר החלפת שפה, תוצג הודעת הנחיה:
  - עברית: **„בחר פרומפט מהרשימה כדי להציג ולהעתיק אותו.”**
  - English: **“Select a prompt from the list to view and copy it.”**

**FR-05 – העתקה אוטומטית:**
- כל לחיצה על לחצן פרומפט תנסה להעתיק ל-Clipboard את מלוא תוכן ה-Markdown המקורי בשפה הנבחרת, לרבות סימוני העיצוב.
- לאחר ניסיון ההעתקה תוצג הודעה קצרה המתאימה לתוצאה בפועל (הצלחה או כישלון).
- במקרה של כישלון ההודעה תנחה את המשתמש להעתיק ידנית מאזור התצוגה.

**FR-06 – העתקה ידנית:**
- המשתמש יכול לסמן טקסט באזור התצוגה ולהעתיקו באמצעות פעולת Copy רגילה, למשל `Ctrl+C`.
- גם בהעתקה ידנית, תוכן ההעתקה חייב להיות Markdown מקורי עם סימוני העיצוב, ולא טקסט מרונדר נטול סימונים.
- הדרישה חלה גם כאשר המשתמש מסמן רק חלק מהתוכן: ההעתקה תשמר את סימוני ה-Markdown הרלוונטיים לקטע הנבחר.

### ב. Edge Cases & Error Handling – מקרי קצה וטיפול בשגיאות
- **העתקה אוטומטית נחסמה או נכשלה:** מציגים את הפרומפט, מציגים הודעת כישלון ומאפשרים העתקה ידנית.
- **קובץ פרומפט חסר או לא נטען:** מציגים הודעת שגיאה באזור התצוגה; שאר הלחצנים ממשיכים לפעול כרגיל. אין להציג תוכן ישן כאילו הוא התוכן שנבחר.
- **החלפת שפה לאחר בחירת פרומפט:** מנקים את התצוגה, מבטלים את ההדגשה ומחזירים את הודעת ההנחיה בשפה החדשה.
- **פרומפט ארוך:** הדף עצמו נגלל, ללא אזור גלילה פנימי וללא הצמדה של לחצני הבחירה.

## 5. דרישות טכניות ואילוצים

### א. דרישות טכניות
- פלטפורמה: אתר Web בעל דף אחד בלבד, ל-Desktop בלבד; אין דרישה להתאמה ל-Mobile או Tablet.
- דפדפנים נתמכים: Google Chrome ו-Microsoft Edge בגרסאות Desktop בלבד.
- שפות ממשק ותוכן: עברית (RTL) ואנגלית (LTR).
- קלט תוכן: 14 קובצי `.md` קיימים.
- שימוש ביכולת Clipboard בדפדפן לצורך ניסיון העתקה אוטומטית, לצד אפשרות להעתקה ידנית.
- אין צורך בתמיכה ב-Offline; הפעלת האתר מחייבת חיבור לאינטרנט.

### ב. אילוצים
- האתר פתוח לכל אדם ללא הרשמה או Login.
- אין לשנות את שבע תוויות הלחצנים בעת החלפת השפה.
- שני לחצני בחירת השפה שומרים על הכיתוב „עברית” ו-“English” בכל מצב.
- אופן המימוש הטכנולוגי, ה-Framework והארכיטקטורה אינם מוכרעים במסמך זה.

## 6. מה מחוץ לטווח – Out of Scope

- התאמת ממשק ייעודית למכשירי Mobile או Tablet.
- תמיכה בדפדפנים שאינם Chrome או Edge ב-Desktop.
- הפעלה במצב Offline.
- הרשמה, Login או ניהול חשבונות משתמשים.
- יצירה או עריכה של תוכן 14 הפרומפטים דרך האתר.
- דפים נוספים מעבר לדף הראשי היחיד.
